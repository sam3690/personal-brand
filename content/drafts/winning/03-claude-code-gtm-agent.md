## THE POST

I turned Claude Code into a GTM agent for my own LinkedIn this week.

It researches, writes, and scores every post before I publish a word.

I build GTM agents for clients. This week I pointed one at my own content problem.

Here's the build. All of it runs inside Claude Code.

The inputs (MCP tools):
→ Apify scrapes my profile and posts, so the agent knows what's actually landing.
→ A web-research tool pulls the live 2026 algorithm rules and trending angles.

The brain:
→ A knowledge base of my voice, my offer, the algorithm, and 100 vetted angles. The agent reads this before it writes a single line.

The team (5 managed sub-agents, one job each):
1. Strategist - picks the angle and the keywords.
2. Hook writer - drafts 3 hooks, keeps the best.
3. Post writer - writes it in my voice.
4. CTA writer - the close and the first comment.
5. QA scorer - grades it out of 100 against the algorithm and blocks anything weak.

I type one command. Out comes a scored draft.

The part I won't automate: hitting publish. A human still approves every post. Same rule I give clients for their sales agents. The guardrail is the product.

That's the difference between "AI writes your posts" and an actual GTM agent. It's not a prompt. It's research, a brain, a team of agents, and a quality gate, wired together.

If you built an agent for your own GTM, what's the one step you'd never hand it?
