# Post Format Skeletons

> Fill-in structures for the 4 formats Usama uses. Ranked by 2026 algorithmic weight (§F).
> The Post Writer (Agent 3) picks one based on the strategist's brief.

---

## 1. 🏆 Carousel / Document (highest weight — 48–72h shelf life)
Use for: frameworks, step-by-steps, the $50 stack, "5 boring automations."

**Intro post (the text above the carousel — 60–100 words):**
```
[HOOK — specific number or "if you" formula]

[1–2 lines of stakes: why this matters / what it cost you]

[Promise of what the swipe delivers]

Swipe → 👇
[CTA from Agent 4]
```
**Slides (6–10):** 1 cover (hook restated big) · 1 problem · 4–6 steps/points (one idea each,
≤20-word headline + 1–2 support lines) · 1 result/proof · 1 CTA slide.
**Design rule:** clean, high-contrast, consistent template. Never blurry/template-looking (kills reach).
Reuse the existing brand carousel assets in `../../carousels/` and `../../brandkit.html`.

---

## 2. 🥈 Native Video (uploaded, <90s, captions burned in)
Use for: hot takes, behind-the-scenes of a build.
```
[On-screen hook in first 2 sec — text overlay]
[Talk to camera or screen-record the workflow]
[One point, one proof, one takeaway]
[Verbal CTA + same CTA in the post text]
```
Captions mandatory (80% watch on mute). Keep the post text short; the video carries it.

---

## 3. 🥉 Single Image (the image must carry a standalone framework)
Use for: a framework graphic, before/after, data viz.
```
[HOOK]

[100–160 words developing the idea]

[CTA from Agent 4]
```
**Image brief:** describe a graphic that communicates value alone (e.g. "before/after: lead response
3 days → 60 sec, two columns, big numbers"). Generate via the brand kit or an image tool.

---

## 4. Text-Only (hook does 100% of the work)
Use for: personal stories (Axios, healthcare), contrarian hot takes.
```
[HOOK — 1–2 lines, curiosity gap]

[Story or argument in 1–2 sentence paragraphs, lots of white space]

[The turn / lesson]

[CTA from Agent 4]
```
120–220 words. No image = the hook and specificity must be airtight.
