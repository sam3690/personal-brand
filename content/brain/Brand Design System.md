# Brand Design System

The **Green Room** kit (v1.2) — dark emerald, film-grain, Anton/Archivo/JetBrains Mono, one hot
gradient per slide. Synced from Usama's Claude Design project ("Brand system design for social
media carousels") into `content/knowledge-base/brand-design-system.md` (full spec: colors, type,
components, slide anatomy) and `carousels/green-room/` (the actual renderable `.dc.html` decks).

This is now the standard visual system for every carousel, banner, CTA image, and featured post —
it replaces the older emerald/gold/Playfair Tailwind kit in `carousels/carousel.html`.

("Single-channel outreach is losing you the deal," Wed 2026-07-22 slot) — see
`carousels/green-room/carousel-multichannel-outbound.dc.html`.
