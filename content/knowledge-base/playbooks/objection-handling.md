# Objection Handling — Speed-to-Lead Install

> Six objections a cold US/EU buyer will actually raise, destroyed using your real
> guarantee, proof, and pricing (not generic rebuttals). Pulled from Hormozi's CLOSER
> "Explain away concerns" step, see `../frameworks/hormozi-closer-sales-script.md`.
> Voice rule: no em dashes.

## 1. "We already use [CRM/tool X]."
Not a replacement, a plug-in. It answers the lead the second it comes in, wherever it lands (form, WhatsApp, DM), then hands it into whatever CRM you already run. You lose nothing you have; you add the 60-second reply you don't.

## 2. "I don't trust AI talking to my customers."
Fair, most AI demos are toys. This isn't a chatbot performing cleverness, it's boring infrastructure: reply, qualify, book. Built by someone who spent 4 years on healthcare-grade systems where a broken workflow loses patient trust, not just a sale. And the Tier-1 guarantee means you see it live and working before you owe anything.

## 3. "How do I know this actually works?"
Three real builds, not slides: a Meta-to-WhatsApp booking system for an interior-design studio, a content engine for a fragrance brand, a voice agent handling enquiries for a medical-sales team. The interior-design studio went from 7-8 booked consultations a month to 27 after it went live, same core mechanic you'd be getting. See `proof-assets.md`. Ask for the Loom.

## 4. "$500 seems too cheap, what's the catch?"
No catch, it's an intro price for the first 2 clients this month (then $750, then $900), because a testimonial is worth more to you right now than the extra $250. The system itself stacks to ~$6,800 in component value (`grand-slam-offer.md`). You're not getting less, you're getting early.

## 5. "Let me think about it / talk to my partner."
Almost never the real objection, it's usually risk. Ask directly: "Is it the price, the timeline, or whether it'll actually work?" Isolate the true one, then answer only that. If it's risk: "That's exactly what the guarantee is for, not live and answering in 7 days, you don't pay." If it's timing: offer to hold the slot 48 hours, no pressure past that.

## 6. "We tried automation before and it broke."
That's the exact gap this closes. Most automation is built by someone optimizing for a demo, not for 2am on a real Tuesday. Point to the Axios fix (millions of Node apps depend on code you shipped) and the healthcare background. Then the 14-day bug-fix window removes the "and if it breaks again" tail risk.

## Delivery rule
Diagnose before you pitch (Hormozi's C-L-O before S). Most of these objections evaporate if the discovery call already surfaced the real fear before you ever quoted a price.
