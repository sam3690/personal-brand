# Playbooks — Client Acquisition & Growth Frameworks

> Proven, applied frameworks for turning this personal brand into a client-getting,
> money-making system. Built from Hormozi's offer/lead-gen work and the automation-agency
> playbook (Saraev model), grounded in Usama's actual offer, ICP, and pipeline.
> "Greater, not bigger": each file closes one real gap, no filler.

## The order to read (and act) in

1. **`first-client-sprint.md`** — START HERE. One goal: 1 paying client in 14 days. Overrides the broader `../../business/revenue-roadmap.md` until client #1 lands.
2. **`grand-slam-offer.md`** — the offer rebuilt with Hormozi's Value Equation + 3 guarantee tiers. The highest-leverage doc. Feeds every outreach touch.
3. **`warm-outreach-reconnect.md`** — the fastest first-client lane: reconnect the warm list with the A-C-A script.
3b. **`proof-assets.md`** — your 3 delivered client builds (UF Designs, Descent Perfumes, medical-sales voice agent) as outreach + content proof.
4. **`core-four-leadgen.md`** — Hormozi's 4 lead channels mapped to Usama's stack with daily targets.
5. **`objection-handling.md`** — the 6 most likely buyer objections, destroyed.
6. **`audience-to-client-funnel.md`** — how build-in-public content converts to paying clients.

Outreach is the job. Content supports it. Products compound it. Do not invert the order before client #1.
